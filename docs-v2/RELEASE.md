# KeranQuests 2.0.0

本版新增 Fabric 1.20.1 独立任务终端与离线可视化编辑器，并修复任务结算、交货、抉择与区域计时问题。服务端仍为 Paper 1.20.1 / Java 17。

## 下载与安装

- **KeranQuests-2.0.0.jar**：放入服务端 `plugins/`。
- **KeranQuests-Client-1.20.1-2.0.0.jar**：配套 Fabric 客户端模组，需要 Fabric API；放入玩家 `mods/`，按 J 打开。
- **KeranQuests-Editor-2.0.0.html**：双击打开离线编辑器，无需部署网站。
- **KeranQuests-Editor-2.0.0.zip**：编辑器、简化示例和配置说明。
- **KeranQuests-2.0.0-bundle.zip**：完整安装交付包。

## 修复

- 拒绝交货不会触发交货完成或领取奖励；对话仅推进其开始时的 NPC 任务目标。
- 重开抉择界面不再撤销一次性阶段结算标记；标记持久化并迁移旧存档。
- 分支接取前完整校验，不再提前完成父任务以腾名额；失败不写入抉择或扣除物品。
- 旧 main04 的提前 progress 配置在内存中自动转换为安全交接。
- 区域缓存每轮检测刷新，停留计时按玩家、任务实例和阶段隔离，掉线清理。
- 阶段消费物品真实扣除并检查当前持有量；重复 complete 不会重复发奖励。
- 任务失效后不再执行该轮任务排期的延迟命令；失败仅重置当前阶段的重接逻辑修正。
- 错误 YAML、未知要求、重复任务树、缺失引用与必需前置循环阻止重载，保留旧配置运行。
- 玩家档案原子替换保存；损坏档案不会被当作空档案加载后覆盖。

## 新增与改进

- 独立章节任务树：关系连线、平移缩放、状态颜色、详情滚动、抉择与放弃确认、HUD 追踪。
- NPC 台词与选项支持客户端对话面板；服务器仍校验每次操作。
- 客户端界面无需箱子菜单、Oraxen、资源包或嵌入式浏览器。未装模组可按配置回退旧菜单。
- 简化配置：defaults、after、steps、enter、talk、trigger、wait、stay、submit 与时间单位。
- 原版 `minecraft:` 物品可直接用于收集、交货和奖励；Oraxen 继续作为可选物品挂钩。
- 离线编辑器可导入旧配置、编辑任务目标与对话节点、校验并导出简化 YAML，高级字段保留。
- 默认烛龙配置压缩重复项、移除箱子布局和冰芯测试赠送，普通物品奖励改为结构化字段。

## 升级注意

先备份整个插件目录及玩家数据，再停服替换 jar。**已有任务配置不会自动覆盖，所有历史 Release 和附件均保留。** 新物品消费逻辑生效后，请去除自己配置里重复的扣除命令。完整安装、旧配置兼容和测试限制见包内 `CONFIGURATION.md`。

本版通过自动回归、服务端/客户端构建及编辑器浏览器检查；真实客户端联机与第三方插件组合仍需在测试服验证。
