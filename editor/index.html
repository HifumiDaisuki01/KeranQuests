可直接编辑完整任务树 YAML。点击“应用源码”后更新关系图；复杂命令、条件与旧字段会被保留。

从一段剧情开始

左侧新增任务，在右侧填写目标和前置关系。连线自动生成；选择“简化导出”会省略默认值，并把普通目标写成 enter / talk / trigger / wait。

导入与保存

可以导入原有任务树或 NPC 对话 YAML。工作台保留高级字段，右侧“高级配置”可编辑生命周期命令、互斥和复杂前置。任务树放入 plugins/KeranQuests/quests/，对话放入 npc/ 任意 .yml 文件，然后执行 /kq reload。重载失败时服务器继续使用旧配置。

原版物品与 Oraxen

minecraft:diamond、minecraft:paper 等原版 ID 无需 Oraxen。原有 Oraxen 物品可继续使用裸 ID 或 oraxen: 前缀。客户端界面无需 Oraxen。

交货与剧情分支

物品要求 consume: true 会在该阶段完成时扣除。NPC 对话选项可设置 require_item / consume、complete_quest 和 quest；先完整校验，再完成原任务并接取分支。end: true 用于“稍后再说”，不会推进对话任务。advance_talk: true 显式表示本选项完成交谈目标。

发布前校验

工作台检查当前章节内部引用、阶段、目标字段和前置循环。跨章节依赖及服务器中的区域、NPC、物品，需要在对应服务器核实。高级源码中的错误不会被自动修正。

数据与隐私

不需要登录或网络，不连接游戏服务器。自动草稿存放在当前浏览器 localStorage，正式交付请使用导出文件。重新导入文件会替换当前章节；先导出当前编辑。
